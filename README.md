# 💰 API de Controle Financeiro

API REST para controle financeiro pessoal, desenvolvida com Python. O projeto tem como objetivo permitir o gerenciamento de receitas e despesas de forma organizada e segura.

## 🎯 Objetivo

Desenvolver uma API para registrar movimentações financeiras, organizar categorias e consultar informações sobre receitas e despesas.

## 🛠️ Tecnologias

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Git e GitHub

## 🚧 Status do projeto

Em desenvolvimento.

## 📌 Funcionalidades planejadas

- [ ] Cadastro e autenticação de usuários
- [ ] Gerenciamento de categorias
- [ ] Registro de receitas e despesas
- [ ] Consulta, edição e exclusão de movimentações
- [ ] Filtros e relatórios financeiros
- [ ] Testes automatizados
